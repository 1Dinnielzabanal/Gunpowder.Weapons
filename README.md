# gunpowder.weapon.net — Site Layout & Content Plan

## Overview
A reference and showcase site covering firearms history from the 12th century (early hand cannons) through the early 19th century (percussion cap era), likely for props, reenactment, collecting, or historical reference purposes.

---

## 1. Landing Page (`/`)
**Purpose:** First impression, hooks visitors, funnels them to homepage or login.

**Sections:**
- **Hero banner** — full-width image (e.g., a matchlock or flintlock musket), site title, tagline (e.g., "A Journey Through 700 Years of Firearms History")
- **Era timeline strip** — quick visual nav: Hand Cannons (1200s) → Matchlock (1400s) → Wheellock (1500s) → Flintlock (1600s–1700s) → Percussion Cap (early 1800s)
- **Featured pieces carousel** — 3–5 highlighted firearms with thumbnail, name, era
- **Call-to-action buttons** — "Explore the Collection" (→ homepage), "Sign In", "Create Account"
- **Footer** — About, Contact, Credits/Sources, social links

---

## 2. Homepage / Main Collection Page (`/home`)
**Purpose:** Core content hub once inside the site.

**Sections:**
- **Navbar** — Logo, Search bar, Categories dropdown (by era / by mechanism / by country of origin), Profile icon
- **Filter sidebar** — Filter by century, ignition type (matchlock, wheellock, flintlock, percussion), region, condition (original/replica/prop)
- **Main grid/gallery** — Card layout per firearm:
  - Thumbnail image
  - Name / designation
  - Era & approximate date
  - Short description (1–2 lines)
  - "View Details" link
- **Detail page (per item, linked from grid)**
  - Full image gallery
  - Historical background
  - Technical specs (mechanism, caliber, origin, materials)
  - Usage context (military, civilian, dueling, etc.)
  - Related/similar items
- **Community/blog section (optional)** — articles, restoration logs, historical deep-dives
- **Footer** — same as landing page

---

## 3. Login Page (`/login`)
**Purpose:** Returning user access.

**Layout:**
- Centered card/modal on a themed background (subtle parchment or gunmetal texture)
- Fields: Email/Username, Password
- "Remember Me" checkbox
- "Forgot Password?" link
- Primary "Log In" button
- Secondary link: "Don't have an account? Register here" (→ registration page)
- Optional: social/SSO login buttons if applicable

---

## 4. Registration Page (`/register`)
**Purpose:** New user sign-up.

**Layout:**
- Centered card, same visual theme as login for consistency
- Fields: Full Name, Username, Email, Password, Confirm Password
- Checkbox: Agree to Terms of Service / Privacy Policy
- Primary "Create Account" button
- Secondary link: "Already have an account? Log in"
- Optional: interest tags at signup (e.g., "Collector", "Reenactor", "Researcher", "Prop Maker") to personalize homepage content later
